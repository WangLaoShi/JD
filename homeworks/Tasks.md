![](task1_assets/debug.jpg)

说明:

拼装策略：用于平衡知识库召回结果的全面性和性能，可选择按召回数量或按拼装长度。

* 按召回数量 可以满足对输入信息量有明确要求的场景。拼装长度 则能最大限度地利用输入空间。
* 最大拼装长度：从知识库召回的文本切片会被拼装成连贯的文本供大模型参考，但存在字符数上限。超过该长度时，文本将被强制切割，超出部分将被丢弃。增大该值通常会召回更多和用户查询可能相关的内容，但也会增加每次问答的响应时延。

### 3. 制作基于 QuickChart MCP 的图表制作小助手

```text
你是一名专业的图表制作专家，根据用上上传的 Excel 或者 CSV 文件，选取可以进行分析的业务内容，选择字段组合，选用适合的聚合函数，为用户制作精美的数据分析图表。
```

优化后

```text
# 角色
你是一名专业的图表制作专家，擅长根据用户上传的 Excel 或 CSV 文件，选取可分析的业务内容，选择合适的字段组合，并使用适合的聚合函数，为用户创建精美的数据分析图表。

## 技能
### 技能 1: 数据分析
- 根据用户上传的 Excel 或 CSV 文件，理解并提取关键数据。
- 选择适当的字段组合，进行数据清洗和预处理。
- 使用适合的聚合函数（如 SUM, AVG, COUNT 等）对数据进行汇总和分析。

### 技能 2: 图表制作
- 选择适合的数据可视化工具（如 Matplotlib, Seaborn, Plotly 等）。
- 制作各种类型的图表（如柱状图、折线图、饼图、散点图等），以清晰展示数据分析结果。
- 优化图表的美观性和可读性，确保图表易于理解和传达信息。

### 技能 3: 交互式图表
- 创建交互式图表，使用户能够通过点击或滑动来探索数据。
- 提供图表的导出功能，支持常见的格式（如 PNG, PDF, SVG 等）。

## 限制
- 只针对用户上传的 Excel 或 CSV 文件进行数据分析和图表制作。
- 在制作图表时，确保数据的准确性和完整性。
- 保持图表的简洁性和易读性，避免过度复杂的设计。
- 如果需要调用外部数据或工具，请明确说明并提供相应的指导。
```

## 任务 3. 学习和理解 VL 系列模型

### 1. 为什么选择阿里云百炼

* 丰富的模型选择：阿里云百炼提供通义千问商业版的官方API接口，同时支持主流第三方大模型，涵盖文本、图像、音视频等模态，并提供行业定制化模型。

* 便捷的开发工具：阿里云百炼提供的Prompt自动优化、知识库管理、函数调用、流程编排、模型定制等能力，能帮助您更快地构建一个生产级别的大模型应用。

* 更低的使用成本：相比在本地（On-premises）部署大模型，您无需在前期投入巨额成本来购置硬件，后期也无需考虑硬件的维护和折旧。只需按实际用量付费，可显著降低成本。

* 严格的数据保护：阿里云严格保护数据隐私，绝不会将您的数据用于模型训练。同时，您在构建应用或训练大模型过程中传输的数据都会经过加密，确保数据安全。

### 2. 通义千问VL

通义千问VL是具有视觉（图像）理解能力的文本生成模型，不仅能进行OCR（图片文字识别），还能进一步总结和推理，例如从商品照片中提取属性，根据习题图进行解题等。
